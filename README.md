# 👨🏻‍💻 Lucas Arruda Leme

**`Software Developer | Pentester | Full Stack Developer | System Analyst`**

Me chamo Lucas Arruda Leme, tenho 22 anos e sou formado em **Análise e Desenvolvimento de Sistemas pela Universidade São Francisco (USF)**.

Tenho foco em desenvolvimento de software, principalmente no backend utilizando **Python**, criando APIs REST, automações de processos e aplicações web. Também possuo conhecimentos em desenvolvimento frontend com **JavaScript**, permitindo desenvolver soluções completas, desde a lógica de negócio até a interface do usuário.

Neste GitHub compartilho projetos desenvolvidos para aprimorar minhas habilidades, explorar novas tecnologias e aplicar boas práticas de desenvolvimento de software. Estou sempre buscando evoluir tecnicamente e criar soluções eficientes para problemas reais.
